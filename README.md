# ROAM Travel Journal

A modern, responsive travel blog designed to inspire people to explore destinations, discover different cultures, and plan memorable adventures.

## Overview

ROAM Travel Journal is a travel-focused blog website featuring destination articles, travel inspiration, and practical travel tips. The website uses a clean, card-based layout to make articles easy to browse and read across desktop, tablet, and mobile devices.

## Features

- **Homepage:** A welcoming travel-themed introduction and article feed.
- **Article cards:** Travel stories presented in a visually organized layout.
- **Destination articles:** Dedicated pages for Bali, Italy, Kyoto, and Tanzania.
- **Travel tips:** A separate page with practical travel advice.
- **Navigation:** Links that help visitors explore the website.
- **Responsive design:** Layouts designed to adapt to different screen sizes.
- **Visual consistency:** Coordinated colors, typography, spacing, and interactive hover effects.
- **Accessibility:** Keyboard accessibility and reduced-motion preferences.

## Technologies Used

- HTML5 — semantic page structure and article content.
- CSS3 — styling, responsive layouts, spacing, and visual effects.
- Git — version control and tracking development progress.
- GitHub — source code hosting and collaboration.
- GitHub Pages — website deployment, if used for the final live version.

## Getting Started

1. Clone the repository:

   git clone https://github.com/roxaneisaro12/travel-journal.git
   

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser, or run a local development server.

4. Browse the homepage and open the destination articles using the available links.

## Design Approach

The website focuses on readability, clear visual hierarchy, consistent spacing, and a responsive article-card layout. Destination-specific pages provide visitors with more detailed travel content, while the homepage acts as the main entry point for discovering stories.
